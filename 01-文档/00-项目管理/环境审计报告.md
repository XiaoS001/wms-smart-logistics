## 三、还需要安装什么（结论）

**必须补装：**

- Maven —— 影响开发流程
- PowerShell 7 (LTS) —— 影响开发流程
- Maven 阿里云镜像连通 —— 影响开发流程

**建议安装（可选，按需）：**

- **IntelliJ IDEA Community** —— 写 Java 后端最顺手的 IDE；也可以用 VS Code + Java 插件代替。不装的话由 DSH 直接改代码也行。
- **数据库图形客户端（Navicat / HeidiSQL / DBeaver）** —— 看表结构、调数据方便；不装的话 DSH 可以直接跑 SQL。
- **Docker Desktop** —— 任务书技术栈里列了 Docker，用于部署；建议**最后阶段**再装，前期不影响开发。
- **Apifox / Postman** —— 接口调试；其实 DSH 用 curl 就能测，优先级低。
- **把 MySQL 注册为 Windows 服务** —— 免管理员权限的替代方案是每次开机跑一次 `05-部署与运维\scripts\start-mysql.ps1`；想省事就用管理员权限注册服务。

## 四、已知注意事项

1. **MySQL 不会开机自启**：当前是免安装实例，未注册服务。开机后执行 `05-部署与运维\scripts\start-mysql.ps1`。
2. **环境变量需新开窗口生效**：`JAVA_HOME` / `MAVEN_HOME` / `Path` 写入的是用户级变量，已打开的命令行不会自动刷新。
3. **本机原本没有 PowerShell 7**：DSH 会话里 `pwsh` 调用的失败（错误码 `0x3221225794`）是这个原因造成的，不是权限问题。
4. **`.ps1` 脚本必须存为 UTF-8 with BOM**：Windows PowerShell 5.1 会把无 BOM 的 UTF-8 当 ANSI 读，中文会乱码并导致语法错误。工作区内脚本已统一加 BOM。
